Simple Timer

By Justin Kemp

The simplest timer possible, with the user inferace maxing out pure simplicity over everything else

Technology

It will function primarly with Html, Css and Java, and it would function on Chrome, Firefox and most platforms. It will also be hosted on github as well.

Features

It will be clickable from any point on the page. It will also not include any uneeded numebrs to improve simplicity. An alarm will go off once time is up and stop stop shortly after.

Possible Future Features

Far future feautres may include the ability to make your own timer through the site. Also the ability to become an extension to be accesed much quicker.

Basics Features

It will have the simplest design possible, you will be able to select the amount of time you want up until a certain high point. The timer will be able to be manually reset in some way

Advanced

The website will possibly include the screen color changing depending on how long until time is up. It will have a themes setting to have a personal theme added. It will also have an adjustable timer sound
